# 고릴라 컨트롤룸 딜리버리 마스터 시안

고릴라 컨트롤룸 「딜리버리 마스터」 메뉴에 들어갈 화면 기획 시안입니다. 정적 HTML이고 데이터는 모두 더미입니다.

- 딜마 계정 관리 : 목록, 딜마 계정 생성(사업자등록증 OCR, 국세청 진위확인, 이싸인온 계약서 발송), 계정 상세(기본 정보, 계약서, 담당 권역 탭)
- 딜마 지역 관리 : 지역 목록, 지역 상세, 주문 관리 주체 배정
- 정산 : 정산 요약, 세금계산서 발행 내역, 관리비 지급 내역, 패널티 차감 내역, 출금 관리

화면 오른쪽 아래 「개발 명세 보기」에서 화면별 명세, 공통 규칙, 확인이 필요한 질문을 볼 수 있습니다.

계약서 원본 PDF는 이 레포에 넣지 않았습니다.
